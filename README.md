# Primes in tuples I — counterexamples and citation audit

This repository examines "Primes in tuples I" by Daniel A. Goldston, János Pintz, and Cem Y. Yıldırım.

The analysis identifies two problems with Proposition 5, equation (9.5): a missing lower-order
term and an error bound that fails when R grows arbitrarily slowly. 
The preprint calls the same statement Proposition 2′.

**Published paper:** Annals of Mathematics 170 (2009), 819–862.
